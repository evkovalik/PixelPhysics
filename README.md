# Pixel Physics

**Идея:** написать физическую систему для 2D игр, ориентированную на пиксельные взаимодействия (только физика твёрдых тел) и поддерживающую разрушения коллайдеров на уровне пикселей.
Ядро не должно привязываться к конкретному игровому движку и системе отображения, но при этом, быть легко интегрируемым.
Отсутствие визуальной части необходимо для возможности использования системы на выделенном игровом сервере.

## Зачем?
Современные игровые движки по типу Unity плохо работают с пиксельными 2D разрушениями (как в игре Worms, Noita). Проблема в том, что физика игры выполняется на CPU (и требуют Collider), а актуальное состояние игровой карты (текстуры) находится на GPU, из-за чего много потерь времени при синхронизации. Можно оконтурить карту в начале игры (получить коллайдер), но могут появится проблемы с точностью взаимодействия (оно уже не пиксельное).

Есть выгодное решение:
1) запомнить значения пикселей, как начальную форму коллайдера и хранить в RAM;
2) при изменении пикселей менять состояние коллайдера и одновременно менять текстуру карты через шейдер (в обоих случаях применяемая форма одинаковая, поэтому конечный результат равный);
3) при запросе пикселя у коллайдера, отдавать актуальное значение без синхронизации с GPU.

Если в пункте 2 коллайдер сделать достаточно "умным", он сможет не менять форму сразу, а применить изменения позже (или в другом потоке). При этом он будет помнить, об изменениях и при запросе пикселя в этой зоне, возвращать корректное значение. Это позволит убрать просадки FPS в момент модификации коллайдеров. При таком подходе синхронизация с GPU минимальна, а состояние пиксельных коллайдеров хранятся в RAM.

Теперь осталась задача в регистрации столкновений таких коллайдеров и поддержке симуляции физики, которую, как раз и должна решить данная библиотека.

## Что реализовано

- [X] столкновения и пересечения (с точностью до пикселя);
- [X] операции сложения и вычитания пикселей из коллайдера (изменение его физической формы);
- [ ] симуляция физических сил;
- [ ] адаптер для движка Unity.

Проект делается на C# 9.0 и netstandard2.1 (для совместимости с Unity).
