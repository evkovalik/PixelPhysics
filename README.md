# Pixel Physics

**Идея:** написать физическую систему для 2D игр, ориентированную на пиксельные взаимодействия (только физика твёрдых тел) и поддерживающую разрушения коллайдеров на уровне пикселей.
Ядро не должно привязываться к конкретному игровому движку и системе отображения, но при этом, быть легко интегрируемым.
Отсутствие визуальной части необходимо для возможности использования системы на выделенном игровом сервере.

## Что реализовано

- [X] столкновения и пересечения (с точностью до пикселя);
- [X] операции сложения и вычитания пикселей из коллайдера (изменение его физической формы);
- [ ] симуляция физических сил;
- [ ] адаптер для движка Unity.

Проект на C# 9.0 и netstandard2.1 (для совместимости с Unity).

Текущая архитектура и детали реализации [тут](Doc/Details.md).
